# 우리 집 밥상

가족이 매일 아침·점심·저녁을 사진으로 남기는 아카이브입니다.
사진은 Google Drive, 기록은 Google Sheets에 저장되고, 화면은 GitHub Pages로 배포해
폰과 컴퓨터 어디서든 접속·설치(PWA)해서 쓸 수 있습니다.

```
폰/PC 브라우저 (index.html, GitHub Pages)
        │  fetch(POST 사진+메모 / GET 목록)
        ▼
Google Apps Script 웹앱  ──▶  Google Sheets (기록)
                          └─▶  Google Drive (사진)
```

## 1. Google 쪽 준비 (5분)

1. https://script.google.com 에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs` 내용을 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
3. 상단 **배포 → 새 배포**를 클릭합니다.
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (링크만 있으면 접근, 로그인 불필요)
4. **배포**를 누르고, 처음 실행 시 권한 요청(Google 계정 인증)에 동의합니다.
5. 발급된 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec` 형태)을 복사해둡니다.

> 시트와 드라이브 폴더는 별도로 만들 필요 없습니다. 처음 저장할 때 스크립트가
> `우리집밥상_기록` 시트와 `우리집밥상_사진` 드라이브 폴더를 자동으로 만듭니다.
> 이미 쓰고 있는 시트/폴더가 있다면 `Code.gs` 맨 위 `SHEET_ID`, `DRIVE_FOLDER_ID`에
> 해당 ID를 넣어주세요.

### 코드를 수정한 뒤에는
Apps Script는 코드를 고쳐도 자동 반영되지 않습니다. **배포 → 배포 관리 → 수정(연필 아이콘)
→ 새 버전**으로 다시 배포해야 웹 앱에 반영됩니다.

## 2. GitHub Pages에 올리기

1. GitHub에 새 저장소를 만들고, 이 폴더(`index.html`, `manifest.json`, `sw.js`, `icon.svg`)를
   루트에 올립니다. (`apps-script/` 폴더는 참고용이니 같이 올려도 되고, 안 올려도 됩니다.)
2. 저장소 **Settings → Pages**에서 브랜치를 `main` / 폴더 `/(root)`로 지정하고 저장합니다.
3. 잠시 후 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

## 3. 앱과 연결하기

1. 위 주소로 접속하면 화면 위쪽에 "아직 부엌과 연결되지 않았어요" 안내가 보입니다.
2. 1번에서 복사한 Apps Script 웹 앱 URL을 붙여넣고 **연결하기**를 누릅니다.
   (이 URL은 각자의 브라우저 `localStorage`에만 저장되며, 가족 모두 같은 URL을 넣으면
   같은 기록을 공유하게 됩니다.)
3. 끼니(아침/점심/저녁)를 고르고 사진을 올린 뒤 **밥상에 올리기**를 누르면 끝입니다.

## 4. 폰에 설치하기

- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: 오른쪽 위 메뉴 → "홈 화면에 추가" / 자동으로 뜨는 설치 배너 사용

설치하면 아이콘이 홈 화면에 생기고, 브라우저 주소창 없이 앱처럼 열립니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (촬영/업로드 + 타임라인). CSS/JS 포함된 단일 파일 |
| `manifest.json` | PWA 설정 (홈 화면 설치용) |
| `sw.js` | 오프라인에서도 화면 껍데기가 뜨도록 하는 서비스 워커 |
| `icon.svg` | 앱 아이콘 |
| `apps-script/Code.gs` | Google Apps Script에 붙여넣을 백엔드 코드 |

## 참고

- 사진은 가족 개인정보이므로, Apps Script 배포 URL을 외부에 공유하지 않는 게 좋습니다.
  URL만 알면 누구든 사진을 올리거나 볼 수 있습니다. 더 엄격하게 하려면 Apps Script
  배포 시 액세스 권한을 "조직 내 사용자"로 바꾸거나, 프론트엔드에 간단한 접속 암호를
  추가하는 방법도 있습니다 (필요하면 이어서 만들어드릴게요).
- Google Sheets를 열어보면 한 끼 한 끼가 한 줄로 쌓이는 걸 그대로 볼 수 있어서,
  나중에 엑셀로 내보내거나 통계를 내기도 편합니다.
